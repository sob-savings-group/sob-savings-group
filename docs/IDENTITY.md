# SOB visual identity (v4)

Frame: royal purple `#5b2a86` and burgundy `#7a1f44`. Gold `#c8962b` marks what is precious (active tab, top rule, sign-in card edge).
Meaning of colour (never decoration): emerald `#0f8a5f` = savings and money that grows; sapphire `#1f5fbf` = loans and money owed; amber `#d98a0b` = waiting; rich red `#c42a3d` and coral = warnings and alerts.
Page is warm ivory `#faf6f2`; text is deep aubergine `#2a1730`. All colours are CSS variables at the end of `app/styles.css`: change them there, nowhere else.
Contrast checked: body text 15:1, grey text 6:1+, white on purple 9.9:1, status text on its tint 5.4:1+.
